# Tournament Registration Telegram Bot

Программный модуль в виде Телеграм-бота для автоматизированной регистрации участников на киберспортивные турниры. Проект реализован на языке Python с применением асинхронного фреймворка `aiogram` 3-го поколения и встраиваемой реляционной базы данных SQLite.

---

## Назначение и архитектура

Бот предназначен для сбора, валидации и централизованного хранения заявок от игроков по различным киберспортивным дисциплинам. Взаимодействие с пользователем построено на базе машины состояний (Finite State Machine, FSM), что обеспечивает последовательный ввод данных и исключает ошибки при формировании анкеты.

---

## Используемые технологии

* **Python 3.10+** — основной язык программирования.
* **Aiogram 3** — асинхронный фреймворк для работы с Telegram Bot API.
* **SQLite3** — реляционная СУБД для локального хранения реестра участников.
* **Python-dotenv** — библиотека для безопасного импорта конфиденциальных параметров (токена API) из переменных окружения.
